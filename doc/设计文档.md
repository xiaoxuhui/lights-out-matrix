# 熄灯问题操作矩阵：设计

- 版本：1
- 日期：2026-10-31
- 状态：结果定义已确认，输出 n×n 点击方案。

## 目标

1. 明确 n×n 棋盘与 n²×n² 操作矩阵的区别。
2. 用绿/红色表示二元矩阵，提供清楚的行列含义。
3. 矩阵逻辑独立于界面，使用 Node 内置测试框架验证。
4. 本地离线可用，构建输出为单个 HTML。

## 分层

- src/core.js：输入校验、格子编号、邻域、矩阵构造；无 DOM 依赖。
- src/app.js、src/style.css、src/index.html：交互、矩阵渲染、响应式布局。
- scripts/build.mjs：将源码合并为 dist/index.html，避免 file:// 下模块加载限制。
- tests/core.test.cjs：独立参考实现与边界测试。

## 数据与边界

使用 Uint8Array 按行存放二元矩阵。邻域按二维坐标计算，不允许横向跨行或环绕。输入只允许 1…20 的整数。大操作矩阵使用 Canvas 绘制和容器内滚动，避免数万个 DOM 节点；缩放时 Canvas 单边不超过 4096 像素。颜色之外提供图例、足够大时显示数字和单元格数值查询。

## 求解

最终需求覆盖之前关于消元结果矩阵的定义：求解 A·x=b，输出 x 的 n×n 排列。输入绿色表示亮，输出绿色表示按一次。采用位打包 Uint32Array 实现 GF(2) 高斯–约旦消元，交换行和异或行，保留主元列；若零系数行常数为 1 则无解。自由变量置零。报告秩和自由变量数；不求最少点击数。

编辑棋盘立即重新求解。n 改变后生成全灭输入，不隐式保留尺寸不匹配的状态。输入独立于结果显示模式。结果验证使用邻域翻转原输入，不依赖消元实现。

## 可见消元过程

新增可折叠的过程区，默认展开以便查看，显示 [A|b] 的逐步变换。首次渲染过程时调用同一求解器的可选记录模式，保存主元、交换、异或、自由列事件，而非为每步复制整张矩阵。步骤播放器维护一份可变增广矩阵；换行和 XOR 均为自逆运算，因此前后跳转可精确回放。选择主元和自由列事件不修改数据。

src/elimination.js 单独负责过程 UI；不与输入求解绑定细节混写。提供开始、上一步、下一步、最后、播放/暂停和完整文字步骤；显示当前行运算、主元、异或真值规则和终局解读。数字始终可放大阅读，颜色保持绿色=1、红色=0。大矩阵在容器内滚动，Canvas 单边不超过 4096。编辑输入立即停止并重置过程；“都不显示”模式隐藏过程。“只显示结果”仍可展开求解过程。

完整文字记录按需生成，避免默认创建数万个步骤节点。记录行操作而非完整矩阵快照，内存随行操作数增长。

## 两阶段顺序（用户确认）

先前向消元：从左到右选主元，只对主元下方行做异或，缺主元列继续检查。再反向消元：从最后一个主元向前，只对主元上方行做异或。记录中包含显式阶段分界事件，各行操作标记 lower / upper；界面显示“第一阶段：消左下部分”“第二阶段：消右上部分”。有自由列时按主元位置定义上下，不错误假设主元都在主对角线上。
