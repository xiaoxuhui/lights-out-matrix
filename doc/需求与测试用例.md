# 熄灯问题操作矩阵：需求与测试用例

- 日期：2026-10-31
- 状态：已确认。用户最终要求输入灯光，输出 n×n 点击方案。
- 交付：本地独立网页程序，可双击打开，不需要安装依赖。

## 规则

输入棋盘边长 n。棋盘为 n×n，点击自身及上下左右会翻转，边界不环绕。运算在 GF(2) 中进行。格子从左到右、从上到下编号 1…n²。

操作矩阵 A 为 n²×n²，A[i,j]=1 表示点击第 j 格会翻转第 i 格，否则为 0。1 用绿色显示，0 用红色显示，同时可显示数字以辅助识别。

输入棋盘同样为 n×n：绿色=亮，红色=灭，点击输入格切换灯光。目标全灭。求解 A·x=b（模 2），结果 x 排成 n×n：绿色=按一次，红色=不按。输入和输出的颜色语义必须分别标注。

提供四个显示模式：都不显示、只显示操作矩阵、只显示结果、全部显示；输入棋盘始终可编辑。隐藏仅控制可见性，不能改变计算。有多解时将自由变量置零，给一组可行解，不声称最少步数；无解必须明确提示，不显示误导方案。支持 n=1…20。

## 验收用例

| 编号 | 输入或操作 | 预期 |
| --- | --- | --- |
| U01 | n=1 | A=[[1]] |
| U02 | n=2 | A=[[1,1,1,0],[1,1,0,1],[1,0,1,1],[0,1,1,1]] |
| U03 | n=3 | A 为 9×9；角、边、中心列分别有 3、4、5 个 1 |
| U04 | n≥2 的行末与下一行行首 | 不是左右相邻，不出现跨行连接 |
| U05 | 非正数、小数、空值、超出上限 | 显示清楚错误，保留上次有效结果 |
| U06 | 切换四种显示模式 | 操作矩阵和结果独立隐藏，计算值不变 |
| U07 | n=2，输入 b=[1,1,1,0] | 输出 x=[1,0,0,0]，实际点击后全灭 |
| U08 | 桌面、窄屏、键盘 Enter | 布局可用，表单正常提交 |
| U09 | n=4，多解输入 | 返回可验证的一个解，并说明多解 |
| U10 | n=4，只有左上角亮 | 明确无解，结果格不伪装为全零解 |
| U11 | 任意棋盘编辑、全亮、全灭、示例 | 自动更新求解结果；全灭时明确无需操作 |
| U12 | 验证方案 | 将方案应用到原输入，实际得到全灭棋盘 |
| U13 | 展开高斯消元过程 | 显示初始增广矩阵 [A\|b]，逐步显示选主元、换行、整行异或 |
| U14 | 下一步、上一步、到最后、回到开始 | 矩阵与步骤一致；后退可准确还原；不改变输入与原有求解结果 |
| U15 | 多解或无解的最后一步 | 标出自由变量或矛盾行，并解释怎样读取解 |
| U16 | 展开过程后编辑输入或改变 n | 过程重置为对应新输入的初始增广矩阵，停止播放 |
| U17 | 查看完整文字步骤、自动播放与暂停 | 可以逐行阅读真实计算步骤；自动播放可停，结束自动停止 |
