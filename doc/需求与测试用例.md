# 熄灯问题操作矩阵：需求与测试用例

- 日期：2026-10-31
- 状态：基础规则已确认；“结果”的数学定义等待用户确认。
- 交付：本地独立网页程序，可双击打开，不需要安装依赖。

## 规则

输入棋盘边长 n。棋盘为 n×n，点击自身及上下左右会翻转，边界不环绕。运算在 GF(2) 中进行。格子从左到右、从上到下编号 1…n²。

操作矩阵 A 为 n²×n²，A[i,j]=1 表示点击第 j 格会翻转第 i 格，否则为 0。1 用绿色显示，0 用红色显示，同时可显示数字以辅助识别。

提供四个显示模式：都不显示、只显示操作矩阵、只显示结果、全部显示。隐藏仅控制可见性，不能改变计算。结果定义确认前不实现依赖该定义的计算。

## 验收用例

| 编号 | 输入或操作 | 预期 |
| --- | --- | --- |
| U01 | n=1 | A=[[1]] |
| U02 | n=2 | A=[[1,1,1,0],[1,1,0,1],[1,0,1,1],[0,1,1,1]] |
| U03 | n=3 | A 为 9×9；角、边、中心列分别有 3、4、5 个 1 |
| U04 | n≥2 的行末与下一行行首 | 不是左右相邻，不出现跨行连接 |
| U05 | 非正数、小数、空值、超出上限 | 显示清楚错误，保留上次有效结果 |
| U06 | 切换四种显示模式 | 操作矩阵和结果独立隐藏，计算值不变 |
| U07 | 用户确认结果定义后 | 补充可复算的结果示例 |
| U08 | 桌面、窄屏、键盘 Enter | 布局可用，表单正常提交 |
